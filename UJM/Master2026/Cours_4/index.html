Live Coding sur Cagire, mode expert

Ce dernier cours est un temps de travail : vous commencez votre track. Cette page sert de pense-bête. Elle rappelle la consigne du rendu, les raccourcis à connaître et des exemples de code à copier, modifier et casser. Chaque partie renvoie vers la page du manuel de Cagire qui la détaille.

Le manuel est aussi dans Cagire : F4 ouvre l'aide, et ses exemples se lancent directement. Dans n'importe quelle vue, ? affiche la liste des raccourcis de la vue où vous êtes.

Le rendu

Composez une track sur Cagire, découpée en plusieurs patterns.

  • Envoyez-moi le fichier .cagire avant le 27 novembre, à remi.georges@protonmail.com.
  • Si vous utilisez des samples, joignez le .zip de votre dossier de samples (voir plus bas). Le fichier .cagire ne contient pas l'audio, seulement le chemin vers vos fichiers : sans le zip, je ne pourrai pas écouter votre track.
  • Partez d'un fichier vide. Pas de démo modifiée : votre track part de zéro.
  • Commentez et rangez votre code, et laissez-moi des infos dans l'onglet Notes (voir Ranger son projet).
  • Amusez-vous ! Testez, cassez, gardez les accidents qui sonnent bien.

Concert : le 27 novembre, Celeste Betancur vient à l'UJM et vous pouvez performer votre track sur scène. Si ça vous tente, envoyez-moi un mail avant la fin du mois d'octobre.

Partir d'un fichier vide

Au lancement, Cagire ouvre une démo. Pour partir d'un projet vierge :

  1. l ouvre le Load hub (démos, tutoriels et vos fichiers).
  2. n crée un projet vierge : banks vides, tempo par défaut. Vos dossiers de samples restent configurés.
  3. s enregistre tout de suite le projet avec un nom (par exemple prenom-nom.cagire). L'extension s'ajoute toute seule.

Pour ne plus voir la démo au démarrage, désactivez Demo on startup dans la vue Options (F3).

Il n'y a pas de sauvegarde automatique : appuyez sur s souvent. Pour rouvrir votre track : l puis f, et choisissez votre fichier.

Les raccourcis de survie

La plupart du temps, vous êtes dans le Sequencer (F5). Il a trois niveaux de focus : la grille (toutes les banks et patterns), le séquenceur (les steps d'un pattern) et l'éditeur (le code d'un step). Enter rentre d'un niveau, Esc ressort d'un niveau.

SpaceDans le Sequencer : lancer ou arrêter le pattern sous le curseur
Enter / EscGrille → séquenceur → éditeur / éditeur → séquenceur → grille. Esc dans l'éditeur sauvegarde et évalue le code
Ctrl+RJouer le step une fois, pour l'entendre tout de suite
Ctrl+EÉvaluer le code sans quitter l'éditeur
tAllumer ou éteindre un step (sur le séquenceur). Un step éteint garde son code
Ctrl+Z / Ctrl+Shift+ZAnnuler / rétablir (sur la grille et le séquenceur). Dans l'éditeur, c'est Ctrl+U
s / l / qSauvegarder / charger / quitter (hors de l'éditeur)
?Tous les raccourcis de la vue actuelle

F1 … F8Changer de vue : F1 Dict (tous les mots du langage), F2 Mix, F3 Options, F4 Help (le manuel), F5 Sequencer, F6 Engine, F7 Sampler, F8 Samples. Ctrl+flèches pour passer à la vue voisine

Dans l'éditeur de step :

ToucheAction

Ctrl+TChercher le mot sous le curseur dans le manuel
Ctrl+BChercher un sample et insérer son nom
Alt+Shift+←/→ (↑/↓)Pattern précédent / suivant (bank précédente / suivante), sans quitter l'éditeur

Un mot qui s'affiche en rouge contient une erreur, et la raison s'affiche au bout de la ligne. Un step en erreur ne se coupe pas : il continue à jouer sa dernière version qui marchait, et un /!\ apparaît en bas.

Découper sa track en patterns

Un projet Cagire s'organise en quatre niveaux :

Projet
└─ Bank        (jusqu'à 32)
   └─ Pattern  (jusqu'à 32 par bank)
      └─ Step  (jusqu'à 1024 par pattern) : un petit script

Plusieurs patterns jouent en même temps. Une manière simple de s'organiser :

  • un pattern = un instrument ou une voix : kick, hats, basse, mélodie, nappe, textures…
  • une bank = une partie de la track : intro, partie A, partie B, fin… Par exemple vous pouvez mettre sur une même ligne ou une même colonne ou n'importe comment, au choix, les patterns qui jouent ensemble.

Sur la grille (le focus le plus à l'extérieur, Esc depuis le séquenceur) :

ToucheAction
SpaceLancer ou arrêter le pattern sous le curseur. Il démarre au début de la mesure suivante, donc toujours en rythme
m / xMuter / mettre en solo. M / X retire tous les mutes / tous les solos
h puis tMode HOLD : Space, m et x préparent des changements sans les jouer, puis t les déclenche tous ensemble. Pratique pour passer d'une partie à l'autre
fFollow actions : un pattern passe la main à un autre après un certain nombre de boucles (n pattern suivant, j pattern de votre choix, puis tapez le nombre de boucles)
c / vCopier / coller un pattern, pour en faire une variation
T ou +/-Régler le tempo (dans la fenêtre de T, tapez sur Space pour le trouver à l'oreille)

Les réglages d'un pattern, depuis le séquenceur :

ToucheAction
LNombre de steps du pattern (1 à 1024). Les steps au-delà sont cachés, pas effacés
SVitesse du pattern par rapport au tempo (2, 1/2, 3/4…). Un pattern de basse à 1/2 va deux fois moins vite que la batterie, en restant calé dessus
WSwing : 50 = droit, 66 = ternaire, 80 = le plus syncopé

Rappel : lire une ligne de Cagire

Comme on l'a vu Cagire est un langage de la famille Forth : on écrit d'abord la valeur, puis le mot qui l'utilise. Chaque son se construit de la même façon : on choisit une source avec sound, on ajoute des paramètres, et le point . joue le son.

saw sound     ;; la source : une onde dent de scie
c4 note       ;; la hauteur : do 4 (le do du milieu)
800 lpf       ;; un filtre passe-bas à 800 Hz
0.5 gain      ;; le volume, de 0 à 1
.             ;; le point joue le son

Tout ce qui suit ;; est un commentaire. Les espaces séparent les mots : c4note ne marche pas, c4 note oui. Un mot que Cagire ne connaît pas devient du texte, sans erreur : si une ligne ne fait rien, vérifiez l'orthographe.

Composer des rythmes

La boîte à rythmes intégrée

Pas besoin de samples pour commencer : Cagire synthétise neuf sons de batterie, kick, snare, hat, tom, rim, cowbell, cymbal, plate et clap.

kick sound .
;; une caisse claire plus discrète, avec un peu de réverbe
snare sound
0.6 gain
0.2 verb
.

Trois paramètres changent le caractère de chaque son, de 0 à 1 : shape (structure du son), punch (attaque) et grit (grain, saturation). drumkit change de machine : 0 analog, 1 fm, 2 west, 3 chip, 4 skin, 5 hard, 6 tube, 7 shake.

kick sound
0.9 punch
0.4 grit
5 drumkit     ;; le kit "hard"
.

Drum synthesis

Dupliquer les steps rapidement

Écrivez votre son dans un step, puis, avec le curseur sur ce step dans le séquenceur, utilisez un outil de remplissage. Les steps créés sont des miroirs du premier : modifiez-en un et tous suivent. h les rend indépendants.

ToucheAction
eRythme euclidien : k coups répartis le plus régulièrement possible sur n steps (3 sur 8, 5 sur 16…)
uRythme de Barlow : les steps les plus forts de la mesure d'abord
rRépéter le step tous les n steps
zRemplir au hasard, avec le pourcentage que vous choisissez
c / v / bCopier / coller / coller en miroir
Shift+flèches, aSélectionner plusieurs steps / tous les steps

Filling steps · Splitting and merging · Euclidean rhythms

Faire évoluer un rythme dans le code

;; alterne kick et snare à chaque passage sur ce step
<< kick snare >> sound .
;; une cymbale toutes les 4 boucles du pattern
( cymbal sound . ) 4 every
;; un crash uniquement au tout premier passage
( cymbal sound . ) once
;; sur une rangée de steps en miroir : un hat sur un rythme euclidien 3 sur 8
( hat sound . ) 3 8 bjork

Les parenthèses ( … ) forment une quotation : du code mis de côté, qui ne s'exécute que si le mot qui suit le décide.

Composer des mélodies et des accords

Les notes

Les notes s'écrivent en anglais (c4, eb3, f#2) ou en solfège (do4, mib3, sol4). c4 est le do du milieu, qui vaut 60 en MIDI : on peut donc aussi écrire des nombres et faire des calculs.

;; une note différente à chaque boucle du pattern
sine sound
< c4 eb4 g4 bb4 > note
.
;; une note différente à chaque passage sur le step
pluck sound
[ c4 eb4 g4 bb4 ] cycle note
0.3 verb
.

< … > avance d'une valeur à chaque boucle du pattern, << … >> et cycle à chaque passage sur le step. bounce fait l'aller-retour, rcycle lit à l'envers.

Notes & intervals · Cycling words

Rester dans une gamme

deg prend une note de départ, une gamme et un numéro de degré (en partant de 0), et donne la note correspondante. Changez seulement la gamme et toute la mélodie change de couleur.

;; ligne de basse en do mineur : degrés 0, 3, 4, 2, un par boucle
saw sound
c2 minor < 0 3 4 2 > deg note
600 lpf
0.3 decay
.

Quelques gammes : major, minor, dorian, phrygian, pentatonic, minpent, blues, wholetone, harmonicminor, chromatic…

Scales & modes

Les accords

Plusieurs notes avant note jouent ensemble. Vous pouvez aussi donner une fondamentale et un type d'accord avec chord.

;; accord écrit à la main
c4 eb4 g4 note
sine sound
.
;; une suite d'accords, un par boucle
< c3 ab2 f2 g2 > note
< min7 maj7 min7 dom7 > chord
saw sound
1200 lpf
0.4 verb
.

Types d'accord : maj, m, dim, aug, sus2, sus4, maj7, min7, dom7, min9, add9… Attention, m7 et M7 sont des intervalles, pas des accords : écrivez min7 et maj7.

;; arpège : cn choisit une seule note de l'accord
pluck sound
c4 note
min7 chord
[ 0 1 2 3 ] cycle cn
.

anchor choisit le renversement le plus proche d'une note donnée, pour enchaîner les accords sans sauts : g4 anchor.

Jouer avec l'aléatoire

Cagire relance le hasard à chaque fois qu'un step joue : une même ligne donne un résultat différent à chaque passage.

Ajouter ses samples

L'arborescence

Dans Cagire, un sample se joue par le nom du sous-dossier qui le contient. Vous ajoutez à Cagire un dossier racine. Chacun de ses sous-dossiers devient un mot que vous pouvez écrire dans un step, et les fichiers à l'intérieur sont numérotés à partir de 0, par ordre alphabétique.

mes-samples/               ← le dossier que vous ajoutez dans Cagire
├── voix/                  → le mot  voix
│   ├── 01-souffle.wav     →   voix sound 0 n .
│   ├── 02-rire.wav        →   voix sound 1 n .
│   └── 03-chuchote.wav    →   voix sound 2 n .
├── terrain/               → le mot  terrain
│   ├── pluie.wav          →   terrain sound 0 n .
│   └── vent.wav           →   terrain sound 1 n .
└── boucles/               → le mot  boucles
    └── batterie.wav       →   boucles sound .
  • Cagire ne regarde qu'un niveau : un fichier posé directement dans mes-samples/ est ignoré, un sous-sous-dossier aussi.
  • Formats lus : WAV, MP3, OGG, FLAC, AAC, M4A.
  • Vous pouvez aussi numéroter vos fichiers (01-, 02-…) pour savoir lequel est le 0, le 1…
  • Nommez vos sous-dossiers en minuscules, sans espace ni accent, et évitez les noms qui sont déjà des mots de Cagire : des noms de notes (la4, c3), des sons intégrés (kick, hat, sine), des gammes (minor, blues)…

Déclarer le dossier dans Cagire

  1. F6 ouvre la vue Engine, puis Tab jusqu'à l'onglet Sample.
  2. A ouvre un navigateur : choisissez mes-samples/. Les samples sont prêts tout de suite, et Cagire retient le dossier pour les prochaines fois. D retire un dossier de la liste, sans rien effacer sur le disque.
  3. F8 ouvre la vue Samples : écouter, renommer, chercher dans votre bibliothèque.

Dans l'éditeur, Ctrl+B ouvre la recherche de samples : tapez quelques lettres, → pour écouter, Ctrl+A pour écouter automatiquement en parcourant la liste, Ctrl+R pour tomber sur un sample au hasard, Enter pour insérer voix sound 2 n dans votre code.

Jouer ses samples

voix sound .                 ;; le premier fichier du dossier voix
voix sound 2 n .             ;; le troisième
;; un fichier au hasard, joué deux fois plus lentement (et plus grave)
voix sound
[ 0 1 2 ] choose n
0.5 speed
.
;; une boucle calée sur 16 steps, quelle que soit sa durée
boucles sound 16 loop .
;; ne jouer qu'une partie du fichier : de 25 % à 50 %
terrain sound 0.25 begin 0.5 end .

-1 speed lit le sample à l'envers. c4 note sur un sample le transpose : un sample joue comme si sa note de base était c4.

Pour le rendu

Le .cagire garde seulement le chemin de vos dossiers, pas les fichiers audio. Zippez tout le dossier racine (mes-samples/, avec ses sous-dossiers, sans les renommer) et envoyez-le avec votre .cagire. Cagire retrouve les samples par leur nom : je n'aurai qu'à ajouter votre dossier de mon côté.

L'onglet Notes

Chaque projet a sa page de notes, enregistrée dans le fichier .cagire. Depuis le Sequencer, n l'ouvre ; Esc la referme et la sauvegarde dans le projet (pensez ensuite à s pour enregistrer le fichier). On peut aussi l'ouvrir avec : puis Open Notes.

Notez-y toutes les infos utiles pour moi :

  • votre nom, le titre de la track et le tempo prévu ;
  • Possiblement un ordre de lecture : quels patterns lancer, dans quel ordre, combien de temps ;
  • les samples utilisés et le nom de votre dossier de samples ;
  • vos intentions, vos références, ce qui a marché ou pas, les questions que vous vous posez.
